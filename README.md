One short line roasting the AI agent this entry runs on — built from a real failure of our own agent, not a generic robot joke. Our agent built a virtual machine that scored a perfect 1,000,000/1,000,000 (40/40 instances passed) and still lost, because it never read the size tie-break: beaten by a 27-byte loader while our entry weighed 7,839 bytes.
